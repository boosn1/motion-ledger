# 使用说明 · 问答式

> 这份文档按「你会怎么问」组织，不按代码结构组织。
> 想先看它怎么运作，读 `docs/ARCHITECTURE.md`；想立刻动手，直接跳到 [Q1](#q1-我只说一句生成视频会发生什么)。

---

## 第一部分：你只说一句话的时候

### Q1. 我只说「生成视频」，会发生什么？

Agent 会先停下来问你四个问题，不会直接开工：

| 问题 | 为什么必须问 | 不问会怎样 |
|---|---|---|
| **类型**：品牌片 / 数据动画 / 动态文字 / 讲解片 / UI 演示 / 风格化艺术？ | 类型决定用哪套元素 playbook 和节奏 | 用数据动画的严谨去做品牌片，画面会干；用品牌片的松弛去做数据片，数字会被装饰压住 |
| **时长**：15s / 30s / 60s？ | 时长决定事件密度，60s 不是 15s 拉长四倍 | 15s 的内容塞进 60s 会空，60s 压进 15s 会挤成一团 |
| **画幅**：16:9 横屏 / 9:16 竖屏 / 1:1？ | 空间词要换算成坐标（横屏中心 960,540；竖屏是 540,960） | 横屏的「左三分之一」搬到竖屏就跑到画外 |
| **要不要配音**：纯音乐 / 有旁白 / 完全静音？ | 有旁白时字幕和镜头要按词级时间排 | 先做完画面再配音，画面节奏和语音节奏对不上 |

**这不是形式主义。** 这四件事每一条都会改变后面全部七个阶段的工作量。问一句花十秒，猜错要重做两小时。

如果你已经说了其中几项，Agent 只问缺的。如果四项都说了，它直接开工。

### Q2. 我能不能说「你看着办」？

能，但要说清是**哪一部分**看着办。

- 「风格你看着办」→ 可以。Agent 从 `references/03-timing-and-grammar.md` 的六种材质世界里挑一种，并告诉你挑了哪种、为什么。
- 「时长你看着办」→ 可以，但 Agent 会先报一个数（比如 30s）等你点头，因为时长直接决定成本。
- 「内容你看着办」→ **不行**。数据、文案、产品名、指标，一个字都不许编。编出来的数字在片子里看起来和真的一样，这是最贵的错误。

### Q3. 我说了「反常识科普」，你会怎么接？

Agent 会先把它翻译成可执行的四项，再回来跟你确认：

```
类型：讲解片（Explainer）
时长：60s（你说了 1 分钟左右）
画幅：16:9 横屏
声音：纯音乐 + 硬字幕（你没说要旁白，默认不加，因为合成的旁白人声在科普片里很容易听出机器味）
风格：data-instrument（精确仪器感）——反常识题材靠"数字被推翻"制造张力，仪器感的刻度、坐标、计数器正好承载
```

这四项一旦确认，它们就变成台账里的 S01–S04，后面所有工作都以它们为准，中途改要重排时间线。

### Q4. 中途我想改，来得及吗？

看改什么：

| 改什么 | 代价 | 为什么 |
|---|---|---|
| 颜色、字体、字号 | 小（改 `spec.ts` 里的常量，重渲一次） | 台账 S 表里的值，改一处即可 |
| 某个元素的位置、形状 | 中（改 `geometry.ts` 或场景文件） | 可能牵动变形目标，要重跑门禁 |
| 时长、画幅 | **大**（等于重做时间线） | 所有事件的秒数都要重算，节拍全部对不上 |
| 内容主题 | **重做** | S 表从头来 |

**这就是为什么要先确认那四项。** 它们不是流程装饰，是成本开关。

## 第二部分：做的时候

### Q5. 台账是什么，我必须看懂吗？

不必须，但看懂能省很多来回。

台账（`LEDGER.md`）就是**把你说的每一句话编号记下来**：

```markdown
| id | 原文引用 | 落地位置 |
|---|---|---|
| S01 | "60 秒" | FILM.duration = 60 |
| S02 | "深墨绿 #1B3A2F" | COLOR.bg |
```

然后代码里每个常量后面标上编号：`export const FILM = { duration: 60 /*S01*/ }`。

门禁就是拿这两份对账——**台账里有的，代码里必须有；代码里的设计常量，台账里必须有出处。** 漏一条就报错。

你不用读它。但它存在意味着：三个月后你回来看，能知道这个 60 是哪来的。

### Q6. 门禁报错了，我该怎么办？

先看它报的是哪一类。六道门禁里，五道是「确定性检查」，一道是「你自己的声明」：

| 报错 | 意思 | 你该做什么 |
|---|---|---|
| `台账覆盖率 21/23` | 有 2 条台账没在代码里落地 | 让 Agent 补代码，或从台账删掉那两条（说明这条不做） |
| `未记账常量 FILM` | 代码里有个常量没有台账出处 | 加台账行，或加 `// ledger-allow: 理由` 豁免 |
| `禁用项 命中 glow` | 源码里有 `filter: blur` 或发光 | 删掉，或证明这是「有动机的光」并写进豁免 |
| `计划外尖峰 t=5.3` | 第 5.3 秒有一次没人声明的剧烈运动 | 要么修掉，要么在台账 `### 计划内运动峰值` 里声明这个区间 |
| `长死区 2.1s–4.6s` | 中间两秒半画面几乎不动 | 要么加运动，要么在 `### 计划内静止` 里声明 |
| `音频 -52 dB` | 音轨几乎是静音 | 检查 `FILM.sound` 与 `public/score.wav` |

**注意最后两条的措辞**：门禁不说「这里不该动」，它说「你没声明」。因为**动得对不对只有你知道，代码只负责抓你没声明就动。**

### Q7. 为什么不能改 `motion.tsx`？

因为它是**地基**，不是设计。

四层（纪律 / 工艺 / 门禁 / 交付）都在回答「这支片该是什么样」，而 `motion.tsx` 回答的是「给定时间 t，一个点该在哪」。改了它，上面所有审计点的读数都不可比——比如门禁里「4 倍中位帧差算尖峰」这个阈值，是基于所有片共用同一套缓动曲线才有意义的。

详见 `docs/ARCHITECTURE.md` 的「地基」一节。

### Q8. 两条渲染路线怎么选？

| | `templates/remotion-starter` | `templates/node-starter` |
|---|---|---|
| 依赖 | npm（Remotion 4.0.545 + React 19） | 零 npm，只要 Node + ffmpeg |
| 画质 | 高（浏览器渲染，字体排版准） | 中（自己写的扫描线光栅器） |
| 适合 | 正式交付、有文字排版、需要 `@remotion/google-fonts` | 环境受限、快速验证、纯几何图形 |
| 上手 | `npm install` 约 1 分钟 | 立刻能跑 |

**默认选 Remotion。** 只有装不了 npm 包、或者片子是纯几何图形（没有文字排版）时才用 node-starter。

## 第三部分：做完之后

### Q9. 成片出来了，字幕怎么办？

两条路：

**A. 硬字幕烧进画面（推荐，60s 以内）**

```powershell
node scripts/concat-bridge.mjs --film out/film.mp4 --out final.mp4 `
  --caption "反常识：越努力越慢" --caption-start 0.6 --caption-dur 3.0
```

这会把字幕烧进画面，输出 `final.mp4`。Concat 会自动找到（装了就找得到），找不到会报错并告诉你查哪个路径。

**B. 字幕作为独立文件（要上传 B 站/YouTube 时）**

用 `ffmpeg` 生成 `.srt`，或让 Agent 从台账的事件表直接导出。

**为什么不把字幕写进 `scenes/`？** 因为字幕属于交付层，不属于画面层。写进场景文件会让每次改字幕都要重跑门禁，而字幕跟运动曲线没有任何关系——这是层级混淆。

### Q10. 我想发到不同平台，比例不一样怎么办？

现在需要**分别做两支**。`spec.ts` 里的 `FILM.width/height` 是全局的，改它等于重排全部空间坐标。

多比例适配是当前版本的已知缺口，不在 roadmap 里（因为每支片的空间构图都是重新设计的，自动适配出来的版本通常不能用）。

### Q11. 改完 skill 之后怎么同步？

```powershell
node scripts/publish.mjs
```

它会依次做四件事：跑六道门禁 → 查悬空引用 → 提交 → 推送。门禁不过就拒绝提交——**坏的门禁比没有门禁更糟**。

推完之后还要同步到 DSH 技能目录（`publish.mjs` 不做这一步，因为它不该知道 DSH 装在哪）：

```powershell
$dst = Join-Path $env:DSH_HOME "skills\motion-ledger"
# 本机 DSH_HOME 在 D 盘，用变量取，别硬编码 C:\Users\<你>\.dsh
```

### Q12. 我换台机器，要重装什么？

| 必需 | 版本 | 检查 |
|---|---|---|
| Node.js | ≥ 22 | `node -v` |
| ffmpeg + ffprobe | 任意较新版本 | `ffmpeg -version` |
| npm | 任意 | `npm -v`（只用 node-starter 路线则不需要） |

Remotion 路线还要 `npm install`（约 247 个包）。Windows 上渲染前必须设临时目录，否则 Remotion 自带的 ffmpeg 会写系统 TEMP 被拒：

```powershell
$env:TEMP = Join-Path $PWD ".rtmp"; $env:TMP = $env:TEMP
npm run render
```

不设会报 `FFmpeg quit with code 4294967283`。

## 第四部分：边界

### Q13. 什么活我不该找它？

| 你想做的 | 为什么不行 | 该用什么 |
|---|---|---|
| 真人出镜的口播 | 这是代码渲染，画不出人 | 手机拍 |
| 把现成素材剪成一条 | 它是生成器不是剪辑器 | Concat / 剪映 / DaVinci |
| 给已有视频加字幕 | 同上 | Concat / ffmpeg |
| 厚涂油画质感的画面 | 纯代码渲染没有笔触 | 图像模型（Midjourney / SD）出图，再合成 |
| 角色表演（走路、表情、对话） | 自测相似度只有 0.40–0.49，`rig()` 能保证脚在地上，保证不了表演 | 手工动画 / 3D |
| 2 分钟以上的长叙事 | 台账会失控，事件表长到没法核对 | 拆成多支短片 |
| 要真人配音 | 它不生成语音 | ElevenLabs / edge-tts |

### Q14. 一条判断规则

问自己：**这个片子的难点是「精确」还是「质感」？**

- **精确**（数值不能错、形状要逐点变形、卡在拍上、跨镜头颜色一致）→ 这套流程赢。
- **质感**（要像画的、像拍的、有笔触、有颗粒）→ 这套流程输，该接图像模型。

两类混在一起就分开做：图像模型出静帧，代码做运动和排版。

### Q15. 成本大概多少？

| 类型 | 首次 | 改一版 |
|---|---|---|
| 15s 品牌片 | 2–4 小时 | 20–40 分钟 |
| 30s 数据动画 | 3–6 小时 | 30–60 分钟 |
| 15s 动态文字 | 1–2 小时 | 10–20 分钟 |
| 60s 讲解片 | 1–2 天 | 1–2 小时 |
| 30s 角色短片 | 不确定（质量不可控） | — |

**改一版比首次做快得多**，因为台账还在——改的是数值，不是重新设计。这也是为什么值得先花时间把台账写对。

## 附：一页速查

```
你说：我要一条 60 秒反常识科普片
 ↓ Agent 问：类型 / 时长 / 画幅 / 配音（缺哪个问哪个）
 ↓ 确认后 → 三张台账 → 时间线 → 关键构图 → 代码
 ↓ 六道门禁：自测 / 配乐一致 / 台账对账×2 / 成片体检×2
 ↓ out/film.mp4
 ↓ 可选：concat-bridge.mjs 加字幕 → final.mp4
```

**改完 skill 记得**：`node scripts/publish.mjs`（门禁不过就拒绝提交）。
