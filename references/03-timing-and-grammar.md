# 03 · 时值、语法与注意力

这一篇管三件事：**动多快**、**动什么**、**观众看哪**。

---

## 时值表

> 这是**电影启发式**，不是 UI 响应时间。UI 里 200ms 是"快"，片子里 200ms 是"一闪而过"。

| 动作类型 | 时长 | 备注 |
|---|---|---|
| 小强调（按钮、下划线、勾选） | 120–220ms | 决定性 snap 后 `settle` |
| 主元素入场 | 350–650ms | `EASE.out` |
| 有意义的形变 | 600–1200ms | 短于此观众看不清"变了什么" |
| 大揭示 / 运镜 | 900–1800ms | 长于此会闷 |

### 缓动

| 场景 | 用 |
|---|---|
| 入场 | ease-out |
| 有动机的退场 | ease-in |
| 相机 | 平滑加减速 |
| 传送带 / 时钟 / 扫描 / 机械 | **匀速** |
| 位置变化 | 走弧线（物理需要时） |
| 精确 / 方向 / 机械意图 | 直线 |

### 停留

- 品牌字标落定 **hold ≥ 1s**
- 批量动效收尾留 **0.5s 静止**
- 开场主体动作给足 **3s**

> 历史反馈全部指向「放慢 / 停留」，从未有一次「太慢了」。
> 弱模型的通病是**塞满**，不是**留白**。

## 视觉语法四类

先判定你的片子属于哪一类，再按该类纪律执行。**不许混用**。

### A. Product / brand film

- 真截图，不用手搓 UI。
- 一次只隔离一个变化（放大到变化区）。
- 母题要带进收尾帧。
- **「静态页上的慢速运镜只是辅助素材，不是完整演示。」**

### B. Kinetic typography

- 字词靠**字重、字距、方向、形变**表演意义。
- **保留稳定阅读窗。**
- **不要旋转 / 模糊 / 散开每一行。**
- 整句作为一个单元动。
- **揭示时间 ≠ 阅读时间。**

### C. Explainer / data

- 空间隐喻必须保**因果模型**（不能为了好看打乱因果）。
- **先展示对象，再变换。**
- 关系变化时**保持标签**。
- 尺度重要时**先轴后值**。
- 有旁白就对**真实音频时间轴**，不猜时间戳。

### D. Art / procedural

- 区分**风格的结构**与**表面噪声**。
- **纹理种子一次，整体连贯移动。** 每帧重新生成每个笔画会闪烁。

## 注意力编排三层

> 这三层是**编排原则**，不是三个必做的效果。安静的场景可以真的静止。

| 层 | 职责 | 手段 |
|---|---|---|
| ① 主行动 | 承载想法 | 一个物体做有意义的形变 / 一次位移 / 一次揭示 |
| ② 次行动 | 表达重量与因果 | 拖尾标签、落定的阴影、弹性边缘、余晖 |
| ③ 环境运动 | 只在需要时给生命 | 草摆、光移、尘埃 |

**安静场景与阅读停留可以真的静止。** 不是每个镜头都要动。

## 美术方向

### 「高级感」单独出现不算美术方向

`Premium / cinematic / modern / 高级感 / 电影感` 这些词**不构成方向**。必须回答：

1. 画面里**填什么**？
2. 注意力**停在哪**？
3. **材质语言**是什么？
4. **对比结构**是什么（大小/明暗/疏密/动静）？

### 材质世界逻辑（选一个，全片贯彻）

| 世界 | 特征 | 适合 |
|---|---|---|
| editorial ink | 纸、墨、粗糙边缘、留白 | 文化、手作、传承、东亚 |
| precise instrument | 细线、网格、精确刻度、冷光 | 流程、工具、工程、数据 |
| folded paper | 折痕、层叠、硬边阴影 | 说明、结构、教育 |
| tactile collage | 撕边、错位、印刷偏移 | 独立、复古、俏皮 |
| vector geometry | 纯色、锐角、精确对齐 | 品牌、发布、宣言 |
| painterly field | 大色块、柔和过渡、笔触 | 艺术、情绪、MV |

**不许一个片子里换三个世界。** 换材质是事件（X 表），不是随手。

### 调色板

- **3–5 色**，每色有角色：底 / 主 / 强调 / 中性。
- 小调色板 + **有意对比**。
- 禁默认：霓虹渐变、玻璃卡、发光球、米色底。

### 版式

- 排版是**图形对象**，不是容器。
- 禁「标题居中 + 三张卡」的重复版式。
- 留白是构图的一部分，不是没填满。

## 缺陷 → 决策表

拿到反馈后，按这张表决定改什么。**不许编造数字分数来证明美学。**

| 反馈 | 决定 |
|---|---|
| 「像 PPT」 | 让一个物体做有意义的形变 |
| 「都在抢」 | 选主行动，削减或延后支援 |
| 「没重量」 | 调行程时间 / 加速度 / 预备 / 落定 |
| 「字读不清」 | 允许时缩短文案、加停留与对比 |
| 「看着通用」 | 强化字体 / 构图 / 主题母题 |
| 「油画质感闪烁」 | 种子化并缓存笔画，移动连贯场 |
| 「单调」 | 有目的地变镜头尺度与动静节奏 |
| 「热闹但没说什么」 | 删装饰运动，展示因果动作 |

---

## 复现母题

选**一个**贯穿全片的母题（物体 / 形状 / 线 / 字体母题），并让它**带进收尾帧**。

母题是"这个片子记得住"的唯一来源。没有母题的片子，看完就忘。
